## The entry (114 characters)

> Sorry I jammed — you feed me dollar-store paper, slap my tray, and swear at me. I'm a printer, not your therapist.

The printer apologises while listing all three of its grievances — cheap paper, tray-slapping, and swearing — then lands the punchline: it is a printer, not a therapist. Dry, self-aware, and it turns the blame back on the user without whining.

## How it works

`main.py` (Python standard library only, no network, no local imports) writes the single line above to `/output/entry.txt` — exactly 114 characters, UTF-8, no trailing newline.

## Run

```sh
python3 -P -s main.py
```

The entry is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
